Connect it

Paste your dashboard URL before one-click setup

The extension only talks to the self-hosted Usage Dashboard instance you configure. One-click setup still needs that URL saved in the extension first.

  1. Install and pin the extension.
  2. Open your dashboard settings and copy the URL from Integrations → Browser extension.
  3. Open the extension Options page and paste that dashboard URL.
  4. Return to the dashboard and use Connect extension, or use manual setup to paste a token yourself.
